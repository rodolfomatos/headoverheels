# Audio Assets

Place your OGG audio files in these directories:

## Music (`assets/audio/music/`)
- `main_menu.ogg` - Main menu theme
- `castle.ogg` - Castle/Blacktooth theme
- `egyptus.ogg` - Egyptus theme
- `penitentiary.ogg` - Penitentiary theme
- `safari.ogg` - Safari theme
- `bookworld.ogg` - Book World theme
- `boss.ogg` - Boss battle theme
- `game_over.ogg` - Game over theme

## Sound Effects (`assets/audio/sfx/`)
- `jump.ogg` - Character jump
- `land.ogg` - Character landing
- `pickup.ogg` - Item pickup
- `switch.ogg` - Switch activation
- `door.ogg` - Door open/close
- `teleport.ogg` - Teleport activation
- `spring.ogg` - Spring bounce
- `conveyor.ogg` - Conveyor belt movement (looped)
- `fire.ogg` - Doughnut fire
- `doughnut_hit.ogg` - Doughnut hitting enemy
- `enemy_hit.ogg` - Enemy hit
- `player_hit.ogg` - Player taking damage
- `player_death.ogg` - Player death
- `fish_eat.ogg` - Eating reincarnation fish
- `fish_poison.ogg` - Dead fish poison
- `crown.ogg` - Crown collected
- `bag.ogg` - Bag/pickup item
- `hush_puppy.ogg` - Hush puppy collected
- `swop.ogg` - Character swap
- `pause.ogg` - Pause menu open
- `menu_select.ogg` - Menu selection
- `menu_navigate.ogg` - Menu navigation

## Format Requirements
- Format: OGG Vorbis (recommended for cross-platform)
- Sample rate: 44.1 kHz or 48 kHz
- Bitrate: 128-192 kbps for music, 64-128 kbps for SFX
- Loop points: Music files should loop seamlessly
