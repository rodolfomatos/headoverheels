# Audio

Nothing in this directory is a recording. The original game's tracks are not
ours to ship, and none of these files came from one.

Every sound is computed:

- `lib/core/audio/hoh_cues.dart` is the sound design: 30 cues, each one the
  recipe for its sound, and the path its file lives at.
- `iso_core`'s `audio.dart` is the synthesiser: pulse waves, noise, glides,
  envelopes and a WAV encoder. Pure Dart, shared with the second game.
- `tool/generate_audio.dart` writes this directory from those two.

```
dart run tool/generate_audio.dart
```

`test/audio_test.dart` re-renders every cue and fails if a file here no longer
matches, so an edited cue cannot ship a stale sound. It also checks that every
cue is audible, brief, unclipped and distinct, that the music loops without a
click, and that the game asks for nothing this directory does not contain.

## What is here

`music/` — eight seamless loops, one per place: the menu, castle, egyptus,
penitentiary, safari, bookworld, the boss and game over. Each has its own key and
timbre; every frequency completes a whole number of cycles in the loop, which is
what makes the loop point inaudible.

`sfx/` — twenty two effects: movement, objects, the two characters being hit,
the fish, the crown, the bag, the puppy, and the menu.

The pubspec's asset list is generated by `scripts/publish_assets.py`, because a
pubspec entry ending in `/` ships only the files directly inside that directory:
without the generated list, a browser build gets this README and nothing else.
